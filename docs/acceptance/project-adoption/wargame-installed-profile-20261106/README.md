# Wargame transport generation from installed Patamaps

On Norway, the Intel native package and the CLI previously compiled from
the installed source package both reproduced the Wargame TypeScript client
and Axum witness byte for byte. Each CLI reported the expected engine and
ran the same two `patamaps link` commands with the historical graph, policy,
projection, timestamp, and packaged routing relation pack.

The existing Wargame guard admitted the run. Both exact archives were
extracted into a new owned prefix and independently compared with the
archived members. The source inventory covered 1,240 files. The sandbox
denied five reads of checkout tools, producer inputs, or owner source and
one write. The prior Rust binary, Next build ID, and contract selection
matched after execution. Both reservations released.

The first attempt stopped before extraction because the precheck compared
the Next build ID text with its recorded digest. The corrected check used
the file digest. The initial failure remains preserved.

This verifies installed generation on the actual Wargame profile. The
source-installed CLI was reused from the earlier witnessed installation.
The Wargame application was neither rebuilt nor started in this run. Its
full installed build and runtime workflow remain open.
