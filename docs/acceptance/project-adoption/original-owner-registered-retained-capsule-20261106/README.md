from the [earlier stopped attempt](../original-owner-registered-watch-postcheck-20261106/README.md).
The trusted runner fixed the capsule path, directory identity, and manifest
digest before launch. It reverified the host, system bindings and full
read-only tree in place. A serialized copy of its registration handle was
refused. The invalid nonce, extra arguments, and work-directory alias
controls also refused before effects.

`project-build-verify` and `project-build-input-key`, and emitted one
nonce-bound result. Independent review verified five stopped process groups,
automatic release of the inner and outer reservations, and the prior
selected attempt and lock. It rehashed 1,816 registration entries, 2,482
selected files and 943 owner inputs. The protected database identity
matched its pre-run record.

The read-only scan measured 129,305,040 bytes of retention headroom.
The guarded run reserved 128,000,000 bytes and recorded 20,946,944 bytes
of growth. The staged Mobile Safari run requires 800,000,000 bytes and
remains unrun. This verified the post-check with the installed guard
still in place. The foreground watcher and active-parent-death checks
remain open.
