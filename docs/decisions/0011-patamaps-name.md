# Project name: Patamaps

On 2026-10-11 the owner selected **Patamaps**, superseding the earlier working
name. Current crates use `patamaps-*`, the commands are `patamaps` and
`patamaps-activator`, and the Python/TypeScript SDK class is `Patamaps`. The
Python package is `patamaps`; both transport distributions use
`patamaps-native-sdk-draft`.

The unpublished draft's schema/profile identifiers, generated addresses and
approval domain now use `patamaps`. Source identities change with this rename.
Old captures and signed approvals do not authorize the renamed compiler or its
new artifact bytes; evaluation and signing must use the current identifiers.
Semantic relationships, admission rules, original consumer fact IDs and the
pinned MetaMap corpus remain unchanged.

Historical acceptance records, source snapshots, archive names and their hashes
retain the names actually tested. They are evidence, not current naming
instructions. [Current rename verification](../acceptance/2026-10-11-patamaps.md)
links fresh native and installation checks. No public publication, production
trust migration or activation is part of this rename.
