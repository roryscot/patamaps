# 0031 — Independent Linux image and browser evidence

The source graph remains evidence of declared connections and captured syntax.
The Linux release lane separately requires BuildKit, a real Linux executable
identified in Cargo's compiler-artifact output, inspection of final image bytes
and effective configuration, real Next.js/generated-client HTTP, and a Chromium
form interaction. Missing required tools or browser runtime blocks acceptance.

The declared builder retains Cargo JSON messages, rustc identity and dependency
notices. A derived inspection Dockerfile appends only an export stage and reuses
the exact builder; it exports explicit artifact/evidence paths without retaining
a duplicate complete Rust builder filesystem. The final image includes the
application, actual compiled-crate and Rust license notices. Image IDs, build
metadata, source/config digests, library/loader inspection and tool commands
remain attributable. Tags alone establish no immutable identity.

Negative images and independent controls cover stage/index/argument/JSON COPY
syntax, Dockerfile-specific ignores, broken packaging, wrong executable,
missing configuration or ELF loader/libraries, genuine AArch64 ELF on the
declared amd64 platform, wrong listener, EXPOSE without a corresponding listener,
and a stale client that still compiles. Native admission and offline replay add
tool-observed artifact/image/runtime facts only after the actual lane succeeds.
The graph engine does not authenticate those tools or reexecute image bytes
during offline verification.

CI retains owned runtime images, containers, source candidates, raw logs,
browser traces/HAR/screenshots and verification records. It stops only owned
runtime containers and process groups. There is no image/registry push, prune,
local VM, production activation, or change to Intel's storage policy. Build and
archive phases each enforce their declared 4 GB growth and 500 MB reserve checks.
These are implemented acceptance requirements; a passing result still requires
running the lane and examining its receipt. MetaMap and exact installed-consumer
acceptance remain separate M7 gates.
