## W0: actual selected-owner no-op and lifecycle

Run the existing installed foreground controller outside an allocating lease.
Pass the exact accepted source/plan/state/context/preparation and the canonical
Intel policy runner; every update must queue independently. Start the watcher
as an owned child whose parent remains observable.

1. Observe the selected input key and one real native no-op update. Require the
   native project-build-no-op report, zero repeated application/generator/test
   commands, current selected-binding verification and the controller's
   completed-project-build-update event. Bound native inspection to 900 seconds,
   the complete update to 1,800 seconds and the whole initial case to 2,100
   seconds. Preserve native command and resource bounds.
2. Verify the controller remains alive and idle for at least two poll intervals,
   without another update, an active build reservation or a held driver lock.
   Check that the same selected pointer, attempt names and execution ledger
   remain unchanged. An owner-declared old readiness result is not renewed.
3. Send SIGTERM to that owned idle controller. Require exit130, no surviving
   owned descendants, and unchanged selected state.
4. In a separate case, start the same watch command through a test-owned parent,
   wait until its independently queued no-op is actively verifying the accepted
   selection, then SIGKILL only that test parent. Require the actual guardian
   chain to stop the watch/native work and release its reservation. Inspect
   actual process/group identities; a stale heartbeat alone cannot release it.
   Freeze a 60-second ordinary cleanup bound. Refuse uncertain ownership.
5. Recheck restored source/tool identities, original pointer/attempt/ledger
   bytes, declared artifacts, scheduler status and owned process absence.
   Preserve any failed run and at most two evidence-backed repairs.

These cases establish real-owner no-op, idle and cancellation behavior only.
They do not establish an edited build, application readiness after an edit,
race recovery during compilation, performance, or complete native crash closure.

attempt budget before running changed builds. Reuse existing sealed dependency
inputs without modifying them. Independently freeze original-MetaMap expected

Run the actual owner generator, production Next build, separate type checking,

then missing-input/refusal recovery and parent death through the normal watcher.

demonstrated defect, with focused regression coverage. Reuse earlier owner
checks that remain valid instead of rerunning unrelated suites.
